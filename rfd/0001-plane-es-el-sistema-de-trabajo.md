# RFD 0001: Plane es nuestro sistema de trabajo

## Contexto
Necesitamos un solo lugar para saber qué estamos haciendo, quién lo hace y en qué estado está. Cinco personas a tiempo parcial no podemos reconciliar tareas repartidas entre chats, documentos y cabezas. Plane ofrece proyectos, work items con jerarquía, estados propios, ciclos y páginas en su plan gratuito.

## Decisión
Usamos Plane como sistema canónico de trabajo: todo cambio real existe como work item con dueño, criterios de aceptación y estado. Los demás sistemas enlazan al trabajo; no lo duplican. GitHub Issues queda desactivado.

## Alternativas consideradas
GitHub Issues y Projects: gratis y junto al código, pero deja fuera a quien no es técnico y obliga a un repositorio por cada proyecto no técnico. Notion como gestor de tareas: sin estados nativos ni jerarquía real en el plan gratuito. Linear: excelente, pero de pago desde el segundo miembro.

## Consecuencias
Aceptamos que el plan gratuito de Plane no integra con GitHub de forma nativa. Lo revisamos el 2026-09-12 y decidimos explícitamente no reemplazar Plane.

## Seguimiento
Un proyecto por producto más tres transversales; catálogo de etiquetas compartido; ciclos de seis semanas.

## Disparador de revisión
Que Plane deje de ofrecer el modelo de ejecución o el acceso que necesitamos.
