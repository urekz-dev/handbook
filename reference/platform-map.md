# Platform Map

Una responsabilidad, un sistema. Discord puede hablar de algo; el sistema dueño lo posee.

| Responsabilidad | Sistema |
|---|---|
| Cómo trabajamos: principios, procesos, políticas, decisiones | Este handbook, en GitHub, publicado en handbook.urekz.com |
| Trabajo y ejecución: proyectos, bets, ciclos, briefs de producto | Plane |
| Código, PRs, CI, decisiones técnicas | GitHub (`urekz-dev`) |
| Registro interno: personas, custodios, herramientas, recuperación, referencia interna y decisiones internas | Notion |
| Archivos formales y medios | Google Drive |
| Secretos de aplicaciones y automatizaciones | Infisical |
| Dominios, DNS y edge | Cloudflare |
| Correo | Zoho Mail |
| Conversación y coordinación del equipo | Discord (servidor interno) |
| Comunidad pública | Discord (Urekz Community) |
| Registro de eventos | Luma |
| Gastos compartidos | Sesterce |
| Analítica web | Cloudflare Web Analytics |

## Cómo elegimos herramientas

Empezamos en el plan gratuito y pagamos cuando una necesidad real lo pide. Antes de añadir una herramienta preguntamos si ya hay un sistema que cumpla esa función. Adoptar, cambiar o retirar una herramienta es un [RFD](../how-we-work/decisiones-rfd.md). Las herramientas que estamos considerando y por qué se registran internamente.
